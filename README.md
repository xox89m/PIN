# ถึงคุณ ♡ — เว็บไซต์จดหมายส่วนตัวพร้อมระบบเสียงบรรยากาศและเชื่อมต่อ Google Drive

เว็บไซต์แบบอินเทอร์แอ็กทีฟสำหรับส่งมอบ **จดหมายขอโทษ** และ **จดหมายสุขสันต์วันเกิด (`H.B.D. 28/10/2026 นะคุณ 🎂🤍`)** บนโต๊ะไม้ยามค่ำคืน พร้อมกล่องใส่จดหมายด้านข้าง ระบบเสียงเปียโนอุ่น ๆ คู่กับเสียงฝนริมหน้าต่าง และระบบบันทึกจดหมายตอบกลับลง Google Drive ของผู้สร้างโดยอัตโนมัติ (ผู้รับไม่ต้องล็อกอินและไม่ต้องใช้รหัสเชิญ)

---

## 1. ระบบเสียงในเว็บไซต์

เว็บไซต์มีระบบสังเคราะห์เสียงในตัวผ่าน Web Audio API (ไม่พึ่งไฟล์ภายนอกที่อาจลิงก์เสียเมื่อนำขึ้น GitHub Pages):
- **เปียโนอุ่น ๆ และเสียงฝน (`ค่าเริ่มต้น`)**: บรรเลงคอร์ดเปียโนนุ่ม ๆ คู่กับเสียงฝนตกกระทบหน้าต่าง เริ่มเล่นอัตโนมัติทันทีที่ผู้เข้าชมแตะปุ่มบนหน้าเว็บครั้งแรก
- **ทำนองกล่องดนตรีวันเกิด**: เมื่อแตะเปิดซองจดหมายวันเกิดข้างแก้วกาแฟ จะมีเสียงกล่องดนตรีบรรเลงทำนอง *Happy Birthday* เบา ๆ คลอไปกับการอ่าน
- **เสียงสัมผัสกระดาษ**: เสียงคลี่กระดาษเมื่อเปิดซองจดหมาย และเสียงพับกระดาษเก็บเข้าซอง
- **ปุ่มควบคุมมุมขวาบน**: ผู้เข้าชมสามารถสลับระหว่าง *เปียโนอุ่น ๆ และเสียงฝน*, *เฉพาะเสียงฝนริมหน้าต่าง*, หรือ *ปิดเสียงทั้งหมด* ได้ตลอดเวลา

> **หากต้องการใส่ไฟล์เพลง `.mp3` ของตัวเองแทนเสียงเปียโนในตัว:**
> 1. นำไฟล์เพลง (เช่น `bgm.mp3`) ไปวางไว้ในโฟลเดอร์ `public/` (จะได้เป็น `public/bgm.mp3`)
> 2. เปิดไฟล์ `src/config.example.ts` แล้วแก้ค่า `customBgmUrl: './bgm.mp3'`

## 2. วิธีนำเว็บไซต์ขึ้นออนไลน์ฟรีบน GitHub Pages

โปรเจกต์นี้ตั้งค่า `base: './'` ใน `vite.config.ts` และเตรียมไฟล์ `.github/workflows/deploy.yml` ไว้ให้พร้อมแล้ว สามารถนำขึ้น GitHub Pages ได้ทันทีโดยไม่มีปัญหาหน้าขาว:

### วิธีที่ง่ายที่สุด (ทำผ่านหน้าเว็บ GitHub โดยไม่ต้องพิมพ์คำสั่งเอง)

1. **ส่งโค้ดขึ้น GitHub**
   - ในหน้า Google AI Studio กดไอคอน **Export to GitHub** (หรือดาวน์โหลดไฟล์ ZIP ของโปรเจกต์แล้วอัปโหลดเข้า Repository ใหม่บน GitHub ของคุณ เช่น ตั้งชื่อ Repository ว่า `to-you`)
   - แนะนำให้ตั้ง Repository เป็น **Public** เพื่อให้ใช้บริการโฮสต์เว็บ GitHub Pages ได้ฟรี (เนื้อหาจดหมายตอบกลับของผู้รับยังคงถูกส่งไปเก็บใน Google Drive ส่วนตัวของคุณอย่างปลอดภัย ไม่ได้ถูกเก็บไว้ใน GitHub)

2. **เปิดใช้งาน GitHub Pages**
   - เข้าไปที่หน้า Repository ของคุณบน GitHub
   - กดแท็บ **Settings** (ด้านบน) → เลือกเมนู **Pages** (แถบด้านซ้าย)
   - ในหัวข้อ **Build and deployment** → ช่อง **Source** ให้เปลี่ยนจาก *Deploy from a branch* เป็น **`GitHub Actions`**

3. **รอระบบสร้างเว็บอัตโนมัติ (~1 นาที)**
   - กดแท็บ **Actions** ด้านบน จะเห็นงานชื่อ **`Deploy to GitHub Pages`** กำลังทำงาน
   - เมื่อขึ้นเครื่องหมายถูกสีเขียว คุณจะได้ลิงก์เว็บไซต์จริง เช่น:
     `https://<ชื่อบัญชี-github-ของคุณ>.github.io/<ชื่อ-repository>/`
   - นำลิงก์นั้นส่งให้คนสำคัญเปิดใช้งานจากมือถือหรือคอมพิวเตอร์ได้ทันที

### วิธีสำรอง (สำหรับผู้ที่ใช้ Git บนเครื่องคอมพิวเตอร์)

```bash
git init
git add .
git commit -m "Initial release: ถึงคุณ ♡"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชีของคุณ>/<ชื่อ-repo>.git
git push -u origin main
```
จากนั้นเข้าไปที่ **Settings → Pages → Source: `GitHub Actions`** ตามขั้นตอนที่ 2 ด้านบน เว็บไซต์จะออนไลน์อัตโนมัติทุกครั้งที่มีการอัปเดตโค้ด
